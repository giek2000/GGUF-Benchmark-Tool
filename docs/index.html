What is it?

GGUF models are the files used to run language models locally with llama.cpp. This tool is a friendly window around llama.cpp's benchmark program, llama-bench. Pick a model, choose how hard to push it, and it tells you the speed in tokens per second — so you can compare models, quantizations, and CPU-vs-GPU settings on your own hardware.

Getting started

  1. Download & run

    Grab GGUFBenchmark.exe from the latest release and double-click it. Windows may warn about an unknown publisher — choose "More info → Run anyway".

  2. Get the engine

    In the top bar, pick a backend and click Download. Start with CPU (x64) if unsure. NVIDIA GPU users pick a CUDA build; AMD/Intel GPU users pick Vulkan.

  3. Load a model

    Click Load GGUF... and choose a .gguf file. Don't have one? Download from Hugging Face.

  4. Run the benchmark

    Pick a preset (or tweak the settings) and click Run Benchmark. The speed in tokens/second appears in the output and is saved to history.

Why download the engine separately? The llama.cpp binaries are large and specific to your GPU type. The app fetches the exact official build you need from GitHub, so the download stays small and always up to date.

Understanding the numbers

TermWhat it means
pp (prompt processing)How fast the model reads your input (higher = faster).
tg (text generation)How fast the model writes new text, in tokens/second.
-ngl (GPU layers)How much of the model runs on the GPU. 0 = CPU only, 99 = all on GPU.
tokens/secondThe headline speed. Roughly, how many word-pieces per second.

FAQ

Is it free?

Yes. It's open source under the MIT license.

Does it work on Mac or Linux?

The pre-built .exe is for Windows x64. On other systems you can run the Python source directly (python gguf_benchmark.py) if you have a llama-bench binary for your platform.

I got a CUDA "unsupported toolchain" error.

Your NVIDIA driver is older than the CUDA build. In the engine bar pick CUDA 12.x (older drivers) and Download, or update your driver, or switch to the Vulkan backend. The app shows these steps automatically when it happens.

Where are my results saved?

Next to the .exe in gguf_benchmark_history.json. You can also export the history to CSV from the Results History tab.

Does it send my data anywhere?

No. It only contacts GitHub when you choose to download a llama.cpp build. Your models and results stay on your machine.

Run from source

git clone https://github.com/giek2000/GGUF-Benchmark-Tool.git
cd GGUF-Benchmark-Tool
python gguf_benchmark.py

Only the Python standard library is required to run. To build the .exe yourself, run build.bat (installs PyInstaller).
